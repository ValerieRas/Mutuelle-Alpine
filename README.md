# Mutuelle Alpine Assurances

Projet de gouvernance et de modélisation des données. L’équipe construit un système qui attribue un score aux déclarations de sinistre pour aider quatre enquêteurs à choisir les dossiers à examiner. La décision d’indemnisation reste humaine.

**Équipe MAA** · BADIN-LÉGER Maxence, RASOLOFOARISON Valérie et Hammadi Sabrina.
