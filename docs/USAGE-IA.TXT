RÈGLES
- Une entrée par usage significatif (pas chaque autocomplétion).
- Règle de l’équipe : à chaque appel à une IA, créer ou compléter une entrée selon AGENTS.md. Remplir tous les champs et demander au membre toute information manquante.
- Être honnête : un journal qui ne mentionne aucun refus ni aucune correction n'est pas crédible.
- Ne JAMAIS coller de données personnelles (même fictives de bronze.assures) dans un outil d'IA externe.

FORMAT D'UNE ENTRÉE (copier-coller)
--------------------------------------------------------------------------------
#ID        : 001
DATE       : AAAA-MM-JJ
AUTEUR     : prénom
LOT TP     : L0..L9
OUTIL      : (ex. Claude Code / Cursor / Copilot / Ollama qwen2.5-coder / ChatGPT ...)
POURQUOI   : (tâche visée, pourquoi l'IA plutôt qu'à la main)
DEMANDE    : (prompt résumé en 1-3 lignes)
RÉSULTAT   : ACCEPTÉ | ACCEPTÉ APRÈS CORRECTION | REFUSÉ
CE QUI A ÉTÉ REFUSÉ / CORRIGÉ :
             (ce qui était faux, risqué ou inadapté ; comment vous l'avez détecté : test, doc, revue)
VÉRIFICATION : (test dbt, pytest, lecture doc officielle, relecture binôme...)
TEMPS      : estimé gagné / perdu
--------------------------------------------------------------------------------
